# Nova AI — лендинг AI-ассистента для команд

Флагманский лендинг из ТЗ «Nova AI»: живая 3D-сфера из частиц, bento-сетка с мини-демо,
sticky-скроллтеллинг, демо-зона «Спроси Nova», табло цен и нестандартные модальные окна.

Чистые **HTML + CSS + JavaScript** — без фреймворков, сборщиков и npm-зависимостей.

## Запуск

```bash
npm start              # поднимет локальный сервер на http://localhost:5173
# или без Node.js:
python3 -m http.server 5173
```

> Нужен именно сервер: при открытии `index.html` двойным кликом (протокол `file://`)
> браузер блокирует локальные шрифты и WebGL-модуль. Вся остальная логика работает.

Для публикации достаточно залить папку на любой статический хостинг —
GitHub Pages, Netlify, Vercel, Cloudflare Pages. `404.html` подхватится автоматически.

## Структура

```
nova-ai/
├── index.html               # лендинг: семантика, SEO, Open Graph, Schema.org
├── 404.html                 # страница ошибки в стиле лендинга
├── site.webmanifest         # PWA-манифест и иконки
├── robots.txt · sitemap.xml
├── package.json             # скрипты start / assets / lighthouse
├── scripts/
│   └── render-assets.py     # генератор видео, фолбэков, OG-картинки, иконок
└── assets/
    ├── css/
    │   ├── fonts.css        # @font-face, только нужные субсеты
    │   ├── tokens.css       # цвета, темы, fluid-типографика, сетка
    │   ├── base.css         # reset, grain, фокус, keyframes, reduced motion, ТВ
    │   ├── components.css   # кнопки, стекло, поля, чипсы, переключатели
    │   ├── modals.css       # <dialog>, bottom sheet, палитра, exit-intent
    │   └── sections/        # по файлу на блок страницы
    ├── js/
    │   ├── core/nova.js     # пространство имён, утилиты, шина событий
    │   ├── data/content.js  # тексты интерактивных демо
    │   ├── modules/         # по модулю на блок: sphere, bento, how, pricing…
    │   ├── modals/          # менеджер окон + trial, video, palette, exit-intent
    │   └── main.js          # запуск модулей и цели аналитики
    ├── fonts/               # Unbounded, Onest — variable woff2
    ├── img/                 # иконки, OG, статичный кадр сферы
    ├── video/               # видеолуп сферы для смартфонов (MP4 + WebM)
    └── vendor/three/        # Three.js 0.160 (локально, CDN — запасной вариант)
```

Порядок CSS важен: токены → база → компоненты → секции → модалки.
Каждый JS-модуль регистрируется через `Nova.define(name, { init })`,
а `main.js` запускает их по очереди. Ошибка в одном модуле не ломает остальные.

## Что реализовано по ТЗ

**Стиль.** Liquid Glass, тёмный фон с зерном, неоновый градиент `#7C5CFF → #3DD6FF → #FF5CAA`,
тёмная и светлая темы (prefers-color-scheme + переключатель с сохранением выбора).

**Шапка.** Сжимается в стеклянную «пилюлю» при скролле вниз и возвращается при скролле вверх.
На мобильном — бургер и меню на весь экран с каскадом пунктов через 60 мс.

**Hero.** Слово «быстрее» каждые 2,5 с меняется на «умнее» и «спокойнее» с размытием.
Сфера на Three.js вращается, наклоняется за курсором до 15° и «пульсирует».

| Устройство | Сфера |
| --- | --- |
| ПК | WebGL, 6400 частиц |
| Планшет | WebGL, 3200 частиц (в 2 раза меньше) |
| Смартфон | видеолуп MP4/WebM ≤ 1,5 МБ под текущую тему |
| ТВ, reduced motion, нет WebGL | статичная картинка |

**Блоки.**
- Marquee логотипов: монохром, на hover — цвет, края растворяются маской.
- Bento из 6 карточек со spotlight и каскадным появлением (blur 12px → 0). Внутри мини-демо:
  печатающийся чат, живой график, drag & drop задач, переводчик, волна записи, переключатели.
- «Как это работает»: sticky-макет, morph экранов через View Transitions, линия прогресса.
  На мобильном — карусель со свайпом.
- «Спроси Nova»: вращающаяся conic-рамка и посимвольный ответ. На ТВ — только чипсы.
- Цифры с count-up за 1,2 с.
- Отзывы: две встречные ленты, пауза на hover.
- Тарифы: табло цифр при смене «Месяц / Год». На мобильном — карусель, по центру «Популярный».
- FAQ на `<details name>` с `interpolate-size: allow-keywords`.
- CTA: буквы собираются при скролле.
- Подвал: 4 колонки, подписка с валидацией, большой обрезанный логотип NOVA.

**Модальные окна** на нативном `<dialog>`: фокус внутри, Esc и «Назад» закрывают окно,
фон блокируется, на смартфоне окна становятся bottom sheet со свайпом вниз.
- «Попробовать бесплатно»: кнопка вырастает в окно. Два шага, успех — конфетти и галочка.
- «Смотреть демо»: превью раскрывается на весь экран, страница размывается до scale .95.
- Командная палитра по `Ctrl/⌘ + K`, на мобильном — через иконку поиска.
- Exit-intent: карточка «+14 дней», только на ПК и один раз за сессию.

**Курсор (ПК).** Светящаяся точка и круг 32 px с задержкой 120 мс. Над кнопками круг
растягивается и «прилипает» — magnetic effect.

**Доступность и устройства.**
- Mobile-first, сетка 4/8/12 колонок и поля по брейкпоинтам от 320 px до 4K.
- Ландшафт смартфона обработан отдельно.
- Учтены safe-area и overscan ТВ.
- Тап-зоны от 44×44, hover только при `(hover: hover)`, заметный фокус.
- Пульты Tizen (10009), webOS (461) и системная «Назад» Android закрывают окна.
- `prefers-reduced-motion` отключает 3D, параллакс и автопрокрутку.

**SEO и производительность.**
- Статичный контент (отзывы, тарифы, FAQ) лежит в HTML.
- Schema.org `SoftwareApplication` + `FAQPage`, Open Graph, манифест, sitemap.
- Шрифты self-hosted с `font-display: swap` и preload.
- Three.js грузится отложенно, в простое. Анимации идут только через transform, opacity и точечный filter.
- Циклы демо останавливаются вне экрана.

## Настройка

- **Аналитика.** Цели (`trial_open`, `trial_step1`, `trial_success`, `video_open`, `subscribe`,
  `exit_intent_shown`) уходят в `dataLayer`. Для Яндекс Метрики подключите счётчик
  и добавьте номер: `<body data-ym="12345678">`.
- **Формы** сейчас имитируют отправку. Подключите свой API в `assets/js/modals/trial.js`
  и `assets/js/modules/subscribe.js`.
- **Домен.** Замените `https://nova-ai.example/` в `index.html`, `robots.txt` и `sitemap.xml`.
- **Тексты демо** лежат в `assets/js/data/content.js`.

## Пересборка ассетов

```bash
pip install numpy pillow fonttools brotli   # плюс ffmpeg в PATH
npm run assets
```

Скрипт считает сферу той же математикой, что и WebGL-версия, и рендерит видеолупы, постеры,
статичный кадр, OG-картинку и иконки.

## Браузеры

Chrome, Edge, Safari 17+, Firefox, Samsung Internet, Smart TV (Tizen, webOS, Android TV).
View Transitions, `::details-content` и `@starting-style` работают как прогрессивное улучшение:
без них интерфейс работает так же, просто без морфа и плавного раскрытия.
