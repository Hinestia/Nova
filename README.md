# Nova AI — лендинг AI-ассистента для команд

Флагманский лендинг из ТЗ «Nova AI»: живая 3D-сфера из частиц, bento-сетка с мини-демо,
sticky-скроллтеллинг, демо-зона «Спроси Nova», табло цен и нестандартные модальные окна.

Чистые **HTML + CSS + JavaScript** — без фреймворков, сборщиков и npm-зависимостей.

**Стиль.** Liquid Glass, тёмный фон с зерном, неоновый градиент `#7C5CFF → #3DD6FF → #FF5CAA`,
тёмная и светлая темы (prefers-color-scheme + переключатель с сохранением выбора).

**Шапка.** Сжимается в стеклянную «пилюлю» при скролле вниз и возвращается при скролле вверх.
На мобильном — бургер и меню на весь экран с каскадом пунктов через 60 мс.

**Hero.** Слово «быстрее» каждые 2,5 с меняется на «умнее» и «спокойнее» с размытием.
Сфера на Three.js вращается, наклоняется за курсором до 15° и «пульсирует».
